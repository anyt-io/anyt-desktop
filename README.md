# AnyT Notebook Desktop

Desktop app for creating and running `.anyt` notebook files locally. Provides a notebook manager, cell editor with drag-and-drop reordering, and local execution of shell commands and AI agent tasks.

## Download

Download the latest version from [Releases](https://github.com/anyt-io/anyt-desktop/releases).

| Platform | File |
|----------|------|
| macOS (Universal) | `AnyT-Notebook-*-mac.dmg` |
| Windows (x64) | `AnyT-Notebook-*-win.exe` |
| Linux (x64) | `AnyT-Notebook-*-linux.AppImage` |

## Auto-Update

The app checks for updates automatically on launch. When a new version is available, you'll be prompted to download and install it.

## File Associations

- `.anyt` — AnyT Notebook
- `.anyt.md` — AnyT Notebook (Markdown)
